순위표

모든 지표는 제출된 거래 목록으로 플랫폼이 동일하게 계산합니다. 매매 정확도 = 비용 포함 본절 이상 전량 청산 / 전체 진입 (Wilson 95%). 평균 수익률 구간은 거래일 단위 부트스트랩입니다.

지표 비교

체크한 run을 지표별로 나란히 봅니다. 회색 띠 = 같은 구간 무작위 기준선의 최소~최대 범위, 세로선 = 기준값(0 또는 PF 1), 가는 막대 = 95% 구간. ▲ = 체크한 run 중 가장 좋은 값.

누적 순수익률 비교

거래당 1단위, 청산일 기준 단순 합(%p). 실제 계좌 수익률이 아닌 신호 품질 비교용입니다. 회색 점선 = 무작위 기준선.

모델 지도

현재 구간의 모든 run을 두 지표로 배치합니다. 점을 클릭하면 비교에 추가·해제됩니다. 빈 원 = 무작위 기준선.

순위표에서 run을 클릭하면 상세가 표시됩니다.
